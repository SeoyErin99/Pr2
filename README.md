# Play in Your Aesthetic

네 가지 미학(Dreamcore · Frutiger Aero · Cottagecore · Fairycore)을 직접 플레이해 보는 웹사이트입니다.

## 폴더 구성

```
index.html                 메인 화면 (3D 이미지 링, 메뉴, 갤러리)
pages/
  dreamcore.html           드림코어 – 양 세기 게임
  frutiger-aero.html       프루티거 에어로 – 아쿠아 헤이븐
  cottagecore.html         코티지코어 – 마음 오두막
  fairycore.html           페어리코어 – 요정의 숲 악단
assets/gallery/<코어>/     갤러리 창 원형 갤러리 사진 (코어별 25장)
```

## 실행

- 폴더를 그대로 두고 `index.html`을 브라우저로 열면 됩니다. 파일을 따로 옮기면 페이지와 사진 연결이 끊깁니다.
- 각 페이지의 3D 장면과 글꼴은 인터넷에서 불러오므로 온라인 상태가 필요합니다.

## GitHub Pages로 공개하기

1. 이 폴더의 내용 전체를 저장소 최상위에 올립니다 (`index.html`이 저장소 첫 화면에 보이도록).
2. 저장소 **Settings → Pages**에서 *Deploy from a branch*, 브랜치 `main`, 폴더 `/ (root)`를 선택하고 저장합니다.
3. 잠시 뒤 표시되는 주소(`https://<아이디>.github.io/<저장소>/`)로 접속합니다.
