# Play in Your Aesthetic

네 가지 미학(Dreamcore · Frutiger Aero · Cottagecore · Fairycore)을 직접 플레이해 보는 웹사이트입니다.

## 폴더 구성

```
index.html                 메인 화면 (3D 이미지 링, 메뉴, 갤러리 사진 포함)
pages/
  dreamcore.html           드림코어 – 꿈속 양 세기 (라운드별 노래 포함)
  frutiger-aero.html       프루티거 에어로 – 푸른 화면 속 장애물 피하기
  cottagecore.html         코티지코어 – 작은 텃밭 지키기
  fairycore.html           페어리코어 – 숲의 멜로디 따라하기
README.md
```

사진과 소리는 모두 각 HTML 파일 안에 들어 있어서, 위 6개 파일만 있으면 사이트 전체가 동작합니다.

## GitHub에 올리기

1. GitHub에서 새 저장소를 만들고 **Add file → Upload files**를 누릅니다.
2. 이 폴더 안의 `index.html`, `README.md`, `pages` 폴더를 한 번에 끌어다 놓습니다.
   (폴더째 끌어다 놓아야 `pages/` 구조가 유지됩니다.)
3. **Commit changes**를 누릅니다.

## GitHub Pages로 공개하기

1. 저장소 **Settings → Pages**에서 *Deploy from a branch*, 브랜치 `main`, 폴더 `/ (root)`를 선택하고 저장합니다.
2. 잠시 뒤 표시되는 주소(`https://<아이디>.github.io/<저장소>/`)로 접속합니다.

## 참고

- 3D 장면 라이브러리와 일부 글꼴은 인터넷에서 불러오므로 온라인 상태가 필요합니다.
